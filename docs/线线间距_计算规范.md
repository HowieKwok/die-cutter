# 线线间距计算规范

本文件描述**当前系统实际实现**的两条近似平行线段间距计算规则。凡是与本文不一致的实现，以本文为准；修改算法须同步修改本文。

## 1. 适用范围

用于所有形如「两条线 → 一个尺寸值」的项：

- 工艺层尺寸项：`线线X`、`线线Y`（见 `CalcFormulaEnum`），由 `DieCutJudge` 求值。
- 点检层：`Model_LineToLineDist.SizeLogicCalculate` / `SizeLogicCalculate_2` 的 X / Y 分支。

不适用：点线、点点、角度项。

## 2. 术语

| 术语 | 含义 |
|---|---|
| 线 | `<see cref="LineGeometry"/>`：四端点 + 可选亚像素点集 |
| 点集 | 抓边模块 metrology 的实测点，`PtsRow` / `PtsCol` 下标一一对应 |
| 共同法向 `n` | 两条线共享的单位法向 `(nR, nC)`，`row`/`col` 分量 |
| 轴距 | 沿列轴（X）或行轴（Y）度量的两线距离 |

## 3. 输入

### 3.1 数据来源

- 工艺层：`LineInfo`，经 `ToGeometry()` 转成 `LineGeometry`。
- 点检层：`LineInfo1`，经 `ToGeometry()` 转成 `LineGeometry`。

几何算法只接受 `LineGeometry`，不接受上述两个业务类型。

### 3.2 点集填充规则

| 产生位置 | 规则 |
|---|---|
| `BaseProDevice.DetectEdgeValueAssign` | 抓边成功时取 `ParamsMeasureLine.hv_CrossRow/hv_CrossColumn` |
| `ImageAlgorithm.FindLine`（metrology 重载） | **仅当单实例**（`hv_LineRowBegin.Length == 1`）时填；多实例时点集跨线摊平、无法归属，一律留空 |
| 交点模块（`DieCutProDeviceMethod.ProcessCoarseLocation`） | 只填四个端点，无点集 |

点集为空时算法退化为「只用两个端点」，属正常路径，不是错误。

## 4. 计算定义

### 4.1 共同法向（整体最小二乘，闭式解）

```
Sxx = Σ dc²,  Syy = Σ dr²,  Sxy = Σ dc·dr      // 两条线的点相对各自质心的偏差累加
φ   = 0.5 · atan2(2·Sxy, Sxx − Syy)            // 线走向（相对列轴）
n   = (nR, nC) = (cos φ, −sin φ)
```

该式对线的走向无要求，接近水平 / 垂直 / 45° 同等有效；不使用斜率参数化。

### 4.2 间距

```
SignedDistance = (cB − cA) · n        // 有符号，A→B 沿 n 的投影
Distance       = |SignedDistance|
```

### 4.3 轴距

```
线线X：Sx = SignedDistance / nC
线线Y：Sy = SignedDistance / nR
无符号版 = |Sx| 或 |Sy|
```

采用除法而非直接取坐标差，是为了消除沿线错位 `δ` 的污染（`Δc = D·n + δ·t`）。

### 4.4 附带量

```
夹角(deg) = acos(|nA · nB|) · 180 / π        // nA、nB 为各线单独拟合的法向
σ_D       = √(sA²/nA + sB²/nB)               // s 为各线相对共同法向的垂直残差标准差（n−1）
```

### 4.5 稳健化

- 每线独立算一次参考法向，剔除到该线距离超过 `max(3 × 中位数, 0.05px)` 的点；只做一次，不迭代。
- 剔除后剩余点少于 2 则保留原点集。

## 5. 常量

| 名称 | 值 | 用途 |
|---|---|---|
| `MinAxisNormal` | `0.05`（约 2.9°） | 法向分量低于此值，该轴距无定义 |
| `CheckTolerancePx` | `0.05` | 交叉校验容差下限（px），也是剔外点的下限 |
| 交叉校验容差 | `max(0.05, 3·σ_D)` | B 的点到 A 线的中位距离与 `Distance` 的允许偏差 |
| 最小点数 | `2` | 少于此值该线不可用 |

## 6. 退化与失败

满足任一条件时 `IsValid = false`：

1. 任一线 `IsAvailable = false`（抓边失败）；
2. 任一线可用点数 < 2；
3. 两线联合散布之和 < `1e-12`（点重合，无法定方向）；
4. `|nR| + |nC| < 0.5`（法向退化）；
5. 所测轴的 `|n_轴| < MinAxisNormal`（线走向与该轴平行）；
6. 交叉校验超差（判为两线点集混组）。

调用方表现：

| 调用点 | 失败表现 |
|---|---|
| `SizeComputationalFormula.DistanceLl` | 返回 `false`，`Val` 保持 `-999` |
| `Model_LineToLineDist.TryLineDistance` | 返回 `false`，`value = NaN`，`Message = "line pair invalid(axis X/Y)"` |

禁止在失败时输出 0 或任意替代值。

## 7. 符号约定（不得混用）

| 调用点 | 约定 |
|---|---|
| `SizeComputationalFormula.DistanceLl` | **无符号**，输出幅值，下游按 `值 ± 容差` 判定 |
| `Model_LineToLineDist` | **有符号**（`line2 − line1` 方向的轴位移），下游按 `|值 − 标准值| ≤ 容差` 判定 |

两者语义不同，不可统一。新增调用点须显式声明采用哪一种。

## 8. 单位与标定

像素域算完再换算，换算在各调用点分别完成，几何层不参与：

```
工艺层：Val = 轴距(px) × coefficient + offset
点检层：Val = 轴距(px) × calibValue_X|Y × 系数 + 补偿
```

## 10. 验证

- 单位：用一个已知间距的合成点集，`Distance` 误差应 ≤ 0.05 px。
- 方向：同一对线旋转 0° / 45° / 90° 各测一次，结果一致（差异在 σ 内）。
- 退化：给 `线线X` 配两条近水平线，必须返回失败而不是大数。
- 混组：把两条线的点拼成一组喂进去，交叉校验必须判失败。

## 11. 已知限制

1. 交点类数据源（`粗定位工具.抓边*`、`极耳左侧交点.抓边*`）无点集，走端点退化，精度低于全点集路径。
2. `GetMetrologyObjectMeasures` 返回的点是否包含被 `distance_threshold` 剔除的点，取决于 HALCON 版本；若含，第 4.5 节会再兜一次（结果不劣化）。
3. 两线投影重叠不足时「间距」本身不唯一，本实现不做该判断，需在上层按工艺决定是否采信。
4. 单系数标定（`coefficient`）隐含像素各向同性；各向异性标定需要在调用点自行处理，几何层不提供。
