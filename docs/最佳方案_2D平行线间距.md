# 最佳方案：两条近似平行线段的间距（2D 平面）

## 1. 一句话

> **不要分别拟合两条线再把结果相减，也不要取中点。**
> 对两条线的**全部亚像素点**做**带平行约束的整体最小二乘**：联合估出一个共同法向 `n`，间距 = 两条线质心在 `n` 上的投影之差。

```
D = | (c_B − c_A) · n |        c_A, c_B 为两条线的点质心，n 为共同单位法向
```

---

## 2. 数学模型（为什么这是最优解）

### 2.1 目标函数

设两条线的点集为 `{p_i}`（N₁ 个）和 `{q_j}`（N₂ 个），噪声各向同性、零均值。
"平行"意味着**两条线共享同一个法向** `n`，于是模型只有 3 个参数：`n`、`d_A`、`d_B`。

```
min  Σ_i ((p_i − c_A)·n)²  +  Σ_j ((q_j − c_B)·n)²      s.t. |n| = 1
```

这正是**整体最小二乘（TLS）**，其解是闭式的：

```
S = Σ_i (p_i−c_A)(p_i−c_A)ᵀ + Σ_j (q_j−c_B)(q_j−c_B)ᵀ      (2×2 散布矩阵)
n = S 的最小特征向量          （线的走向 = S 的最大特征向量）
```

2D 下有解析式，不需要迭代：

```
φ = 1/2 · atan2(2·Sxy, Sxx − Syy)      // 线走向（相对列轴）
n = (cos φ, −sin φ)  in (row, col)     // 单位法向
D = |(c_B − c_A) · n|
```

### 2.2 三个"最优"的性质

**① 统计最优**：各向同性高斯噪声下，上式就是最大似然估计；方向由 `N₁+N₂` 个点共同决定，角度噪声比单线估计降 `√2`。

**② 角度误差被"共模"抵消**：两条线各自的角度误差 `δθ_i` 会以 `|p_i|·δθ_i` 的形式污染各自的截距（`|p_i|` 是线到原点的距离）。
改用共同法向后，两条线共享同一个 `n`，剩下的只有"共同法向扰动 `δn`"与"两质心沿线错位 `δ`"的乘积 `δ·|δn|`；而 `|δn|` 由 `N₁+N₂` 个点共同决定，比单线角度误差又小一个量级，故这一项可忽略。
换句话说：**即便两线夹角有 0.5°，只要用共同法向，距离估计几乎不受影响。**

**③ 与坐标原点无关**：`D` 只依赖两点之差。相比之下，直接把两条线各自的 `Dist` 相减是**错的**——
`Dist_i = n_i·p_i`，若 `n_i` 旋转 `δθ`，`Dist_i` 变化约 `|p_i|·δθ`。图像坐标下 `|p_i|` 可达上千像素，`δθ = 0.3°` 就能带来 **5 px 级**的假误差。**必须先把法向统一。**

### 2.3 不确定度（顺手给出）

```
σ_perp,i = std( (点 − 质心)·n )        每侧的垂直残差
σ_D      = √( σ_perp,A²/N₁ + σ_perp,B²/N₂ )
```

`D ± 1.96·σ_D` 即 95% 置信区间，可作为测量是否可信的判据（也可用于判断两条线是否真的"直"）。

## 3. HALCON 实现（完整、可直接用）

```halcon
* ===================== 输入 =====================
* ContourA, ContourB：两条线的亚像素 XLD 轮廓（各自的点只属于自己那条线）
* 若还没有：edges_sub_pix (Image, Edges, 'lanser2', 0.9, 20, 40)
*           select_contours_xld (Edges, Long, 'contour_length', 100, 1e5, -0.5, 0.5)
*           再按位置/方向把轮廓分成 A、B 两组

* ---------- 1) 每条线独立稳健拟合：只用来定"参考线"和夹角 ----------
fit_line_contour_xld (ContourA, 'tukey', -1, 5, 5, 2, \
                      RA1, CA1, RA2, CA2, NrA, NcA, DistA)
fit_line_contour_xld (ContourB, 'tukey', -1, 5, 5, 2, \
                      RB1, CB1, RB2, CB2, NrB, NcB, DistB)

LA := sqrt(NrA*NrA + NcA*NcA)
LB := sqrt(NrB*NrB + NcB*NcB)
NrA := NrA/LA
NcA := NcA/LA
NrB := NrB/LB
NcB := NcB/LB

* ---------- 2) 取点 + 剔除外点（到参考线距离 > 3×中位数） ----------
get_contour_xld (ContourA, RowA, ColA)
get_contour_xld (ContourB, RowB, ColB)

distance_pl (RowA, ColA, RA1, CA1, RA2, CA2, DA)
distance_pl (RowB, ColB, RB1, CB1, RB2, CB2, DB)
tuple_median (DA, MedA)
tuple_median (DB, MedB)
ThrA := MedA * 3.0
if (ThrA < 0.5)
    ThrA := 0.5
endif
ThrB := MedB * 3.0
if (ThrB < 0.5)
    ThrB := 0.5
endif
RowA := RowA[DA < ThrA]
ColA := ColA[DA < ThrA]
RowB := RowB[DB < ThrB]
ColB := ColB[DB < ThrB]

* ---------- 3) 质心 ----------
tuple_mean (RowA, ar)
tuple_mean (ColA, ac)
tuple_mean (RowB, br)
tuple_mean (ColB, bc)

* ---------- 4) 联合散布矩阵 → 共同法向（整体最小二乘） ----------
dAr := RowA - ar
dAc := ColA - ac
dBr := RowB - br
dBc := ColB - bc

tuple_sum (dAc*dAc, SxxA)
tuple_sum (dAr*dAr, SyyA)
tuple_sum (dAc*dAr, SxyA)
tuple_sum (dBc*dBc, SxxB)
tuple_sum (dBr*dBr, SyyB)
tuple_sum (dBc*dBr, SxyB)

Sxx := SxxA + SxxB
Syy := SyyA + SyyB
Sxy := SxyA + SxyB

PhiDir := 0.5 * atan2(2.0*Sxy, Sxx - Syy)     // 线走向（相对列轴）
Nr     :=  cos(PhiDir)                        // 单位法向
Nc     := -sin(PhiDir)

* ---------- 5) 间距 ----------
Distance := abs((br - ar)*Nr + (bc - ac)*Nc)

* ---------- 6) 平行度（度） ----------
CosA := abs(NrA*NrB + NcA*NcB)
if (CosA > 1.0)
    CosA := 1.0
endif
AngleDeg := acos(CosA) * 180.0 / 3.141592653589793

* ---------- 7) 不确定度 ----------
PrA := dAr*Nr + dAc*Nc
PrB := dBr*Nr + dBc*Nc
tuple_sum (PrA*PrA, QA)
tuple_sum (PrB*PrB, QB)
SA := sqrt(QA/(|PrA| - 1))
SB := sqrt(QB/(|PrB| - 1))
SigmaD := sqrt(SA*SA/|PrA| + SB*SB/|PrB|)

* 结果：Distance ± 1.96*SigmaD，AngleDeg 为两线夹角
```

### 交叉校验（强烈建议保留）

```halcon
distance_pl (RowB, ColB, RA1, CA1, RA2, CA2, DistAll)
tuple_median (DistAll, DistCheck)      // 应与 Distance 相差 < 1e-3
```

两者一致，说明点分组、法向、单位化都没问题；若差很多，几乎一定是"两条线的点混在了一起"。

## 4. 与另外两种做法的对比

| | 中点—中点 | 分别拟合后 `Dist2 − Dist1` | **本方案** |
|---|---|---|---|
| 用到的点 | 4 个端点 | 全部 | 全部 |
| 量纲错误 | 斜边（`d + δ²/2d`） | 无（但**依赖原点**） | 无 |
| 沿线错位 δ | 直接污染 | 不敏感 | 不敏感 |
| 角度误差 | 放大 | `\|p\|·δθ` 直接进结果 | **共模抵消** |
| 多余参数 | — | 两条线各 2 个自由度 | 平行约束，3 个自由度 |
| 误差量级（典型） | 0.1–10 px | 0.5–5 px（原点远时） | **0.02–0.05 px** |

## 5. 边界条件与参数

| 项目 | 说明 |
|---|---|
| `ClippingEndPoints` | 5–15。端点是伪影重灾区，拟合时剔除，但仍用于确定线段端点 |
| 点的来源 | 必须是**亚像素**（`edges_sub_pix` / `measure_pos` / `lines_gauss`）；二值化+区域拟合会引入 0.5 px 量化 |
| 线是"细线" | 用 `lines_gauss` 提**中心线**（`Sigma ≥ w/√3`，w 为线半宽），再做同样的联合估计，得到的是**中心距** |
| 两线宽度不等 | "上边缘到上边缘" ≠ 中心距，先明确测的是内距/外边距/中心距 |
| 线段不重叠 | 投影重叠长度 < 20% 时，"间距"不唯一，应报"某站点间距"或直接判无效 |
| 点集混组 | 最常见的失败原因：两条线的点进了同一组。用交叉校验一查便知 |
| 单位 | 若需 mm：`camera_param` + `plane_pose` 走 metrology，或 `image_points_to_world_plane` 换算后再算 D（**不要**在像素域算完再乘一个常数，透视下会错） |

---

## 6. 输出

| 量 | 含义 | 用途 |
|---|---|---|
| `Distance` | 法向间距（px 或 mm） | 主结果 |
| `SigmaD` | 标准误 | `Distance ± 1.96·SigmaD` 作为置信区间 |
| `AngleDeg` | 两线夹角 | 平行度；> 0.3° 时"单一间距"应谨慎解读 |
| `DistCheck` | 交叉校验值 | 与 `Distance` 比对，验证实现 |
