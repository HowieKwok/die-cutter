# 五金模切 运行控制设计（Idle / Running / Paused）

> 实现日期：2026-11-27。适用于五金模切；激光模切保持原有启停语义，不读本模块。
> 帧队列与 PLC 发布细节见 `docs/五金模切_帧队列与PLC发布设计.md`。

## 1. 三态与唯一真源

`Frame_MetalRun.MetalRunState`：

| 状态 | 流程线程 | 帧触发 | 帧队列 | PLC 结果 | 发布器 |
|---|---|---|---|---|---|
| Idle | 停止 | 自动：PLC 触发但图被丢弃；仿真：不产图 | 空 | 0 | 停止 |
| Running | 正常消费 | 正常 | 正常 | 正常发布 | 运行 |
| Paused | 挂起（当前帧跑完后不再取新帧） | 自动：继续入队（≤8 帧/相机）；仿真：冻结 | 不清 | 不清、不写 0 | 继续运行 |

- 新 UI（工具栏、状态栏、调试界面守门）只读 `MetalRunController.State`。
- `Is_MojuanStart` / `Is_Run` 是兼容镜像，只由 `Server_五金模切` 宿主在状态迁移时写：
  Idle → 两者 false；Running/Paused → 两者 true。
- `Project.GetStates()` 仍是“至少一条流程线程在跑”的帧准入闸门；暂停用 `ProcessServices.Suspend`
  而不 Stop，因此暂停时它保持 true，帧回调继续取号入队，Pending 继续发 PLC。
- `IsMojuanRun` 在本仓库不存在；实际符号是 `Is_MojuanStart`（膜卷生命周期）与 `Is_Run`（启停意图）。
  两者不能全局合并（激光存在“开卷未启动 / 停机未结束”组合）；五金下由三态枚举统一派生，但不改
  `Project` 字段类型（避免二进制不兼容）。

## 2. 动作

### 2.1 开始膜卷（总开关）

1. 状态必须 Idle；宿主校验当前没有遗留流程线程在跑。
2. 校验膜卷号/目录、配方 JSON + 流程 `Instance.xml`。
3. `PrepareFilmRoll`：`Is_MojuanStart=false`，写膜卷号/路径/光源。
4. `ClearBeforeStart`：关闭帧准入 `Accepting` → `Data.Init` → `INIProduct` → 清结果/尺寸/连续NG/统计快照 →
   三路写 0 → 相机计数/仿真标志/点检复位 → 清仿真在途。
5. `StartProduction`：解除仿真冻结 → 启动发布器 → 启动 7 条流程 → 逐条校验线程 → 打开 `Accepting` →
   `Is_MojuanStart=true`。
6. 任一步失败 → `RollbackStart`，回到 Idle。

### 2.2 暂停 / 继续

- 暂停：仿真冻结编排器（`SimulationRuntime.TriggerPaused=true`）→ `五金模切帧门控.Paused=true`（上限 8）
  → 全部 `ProcessServices.Suspend()`。不硬停、不写 PLC、不清队列、不停发布器。
- 继续：`Paused=false` → `Resume()` → 仿真恢复并顺延在途送达。
- 当前帧跑完才停；暂停瞬间尺寸三路若未同时进入等待，可能有一片按等齐超时 NG，这是暂停边界。

### 2.3 结束膜卷

1. Running → 先暂停；Paused 保持。
2. `WaitAllIdle(3s)`；超时拒绝清场。
3. 检查未处理项：帧队列、EA 队列、尺寸未凑齐组、PLC 待发送条数、仿真在途、暂停丢弃数。
4. 有未处理且未确认 → 返回 `NeedsConfirm`，保持 Paused。
5. 确认 → `StopAndClear`：停流程 → 停发布器 → 写 0 → `INIProduct`（唯一一次代际+1、清帧/EA、序号归零）
   → 清结果/尺寸 → 清仿真/显示队列 → 排空 `DataSave` → `Is_MojuanStart=false` → Idle。

## 3. 帧准入与暂停上限

`五金模切帧门控`（`五金模切帧序号.cs`）：

- `Accepting=false`：清场期间拒绝所有新帧（清场后旧回调不能再塞图）；该拒绝不计数、不告警。
- `Accepting=true` 且 `Paused=true`：按相机统计 `QueueGrabImage + alreadyDealGrabImage`，达到 `Limit=8` 后
  在**分配帧号之前**丢弃，不占号、不产生 Pending；首帧触发一次“暂停积压已满”告警。
- 开始时复位丢弃计数与告警去重；继续时只清告警去重、保留累计供结束快照；结束时复位。

## 4. 仿真冻结与单步

- 暂停时 `SimTriggerOrchestrator.Suspend()` 冻结周期槽与在途送达；`Resume()` 顺延 `_pending` 到期时刻并重排。
- `ClearProducts()` 同时清 `_products` 与 `_pending`（修复旧实现漏清在途送达）。
- 单步（仅仿真+Paused）：
  1. 若仿真在途产品 > 0：界面确认「单步将丢弃这些仿真令牌」后调用 `ClearProducts()` 清空，
     再 `WaitAllIdle`、清残留尺寸组；否则旧令牌恢复后会让尺寸帧号回退。
     有帧积压则只处理队首，不推新图。
  2. `SimCamera.StepPush` 推上/下线各一张；用**下线帧队列新增帧的 image_ID**判断接受，
     不用会被钳位的 `DownFrameId`；未接受则跳过尺寸。
  3. `SizeFrameSequencer.PushManualFrameId` 强制尺寸三路同号；`ProcessServices.StepOnce` 按
     裁图→EA→尺寸 分组并发执行一次。
  4. 单步期间 `SimTriggerOrchestrator.ManualStep=true`，抑制下线自动送达，避免恢复后多一个产品令牌。
  5. 单步成功后调用 `LineScanFrameSequencer.SuppressLeadClampOnce()`：恢复运行的首个下线钳位属于
     单步恢复暂态，静默处理，避免弹「线扫帧号错位」。
- 单步处理的是队首帧；暂停瞬间若有积压，先消耗积压。

## 5. UI

工具栏（五金）：

| 状态 | 开始/结束膜卷 | 继续/暂停 | 上一片 | 下一片 |
|---|---|---|---|---|
| Idle | 开始可用 | 禁用（“继续”） | 自动隐藏 / 仿真禁用 | 自动隐藏 / 仿真禁用 |
| Running | 结束可用 | “暂停” | 自动隐藏 / 仿真禁用 | 自动隐藏 / 仿真禁用 |
| Paused（自动） | 结束可用 | “继续” | 自动隐藏 / 仿真禁用 | 自动隐藏 / 仿真禁用 |
| Paused（仿真） | 结束可用 | “继续” | 可用 | 可用 |

- 底部状态栏 `RunStateChip`：空闲 灰 / 暂停 橙 / 运行 绿，图标 + 中文状态 + 中文 Tooltip；仅五金显示。
- 运行中禁用顶部「调试设置」「工艺标准」菜单；暂停/空闲恢复，便于暂停后调参。
- 自动模式隐藏「上一片/下一片」；仅仿真暂停时显示。
- 五金隐藏 CCD 软件复位与清除纠偏数据；激光保留。
- 调试设置：五金禁用 `BtnRunLoop`；`BtnRunStop` 仅 Idle 可用；`BtnRunOnce` 仅 Idle/Paused 可用。

## 7. 边界

- PLC 是标量点位、无帧号回执；长时间暂停后结果与物理片的对应只能靠 FIFO，操作上应尽快恢复或结束。
- 暂停上限只约束帧队列，不约束结果队列；PLC 断线时 Pending 仍可能填满 64 条并触发现有溢出告警。
- 结束膜卷取消后保持 Paused，不自动恢复 Running。
- 统计合片/CSV 保存队列属于统计输出，不纳入 PLC 未处理项；开始膜卷时由 `Data.Init` 重置。
- 重启后同膜卷号目录已存在会被拒绝，沿用既有规则；需要新膜卷号或运维清理目录。
